Add your Anthropic API key

Don't have one? Sign in at console.anthropic.com, click API keys, then Create key. The key starts with sk-ant-.

Why your own key? Each user runs Claude on their own Anthropic billing — you see exactly what your drafts cost, IT doesn't have to manage shared spend, and your key never leaves iteria's tenancy.
  • Stored encrypted in USER_PROFILES (Oracle 23ai).
  • Decrypted server-side only when you generate a draft.
  • Never logged, never sent to other users, never returned to the browser.

You can change or remove your key any time from My account → API access.
